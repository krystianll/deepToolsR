usage: plotHeatmapR -m matrix.gz
help: plotHeatmapR -h / plotHeatmapR --help

This tool creates a heatmap for scores associated with genomic regions. The program requires a
matrix file generated by the tool ``computeMatrixR``.

options:
  --config PATH         [global] Options file path, or auto for the default file. (default: auto)
  -p N|max|auto, --numberOfProcessors N|max|auto
                        [global] Threads: positive integer, max, or auto. (default: auto)

Required arguments:
  --matrixFile MATRIXFILE, -m MATRIXFILE
                        [global] Matrix file from the computeMatrixR tool. (default: None)
  --outFileName OUTFILENAME, -out OUTFILENAME, -o OUTFILENAME
                        [global] File name to save the image to. The file ending will be used to
                        determine the image format. The available options are: "png", "eps", "pdf"
                        and "svg", e.g., MyHeatmap.png. (default: None)

Output options:
  --outFileSortedRegions FILE
                        [global] File name into which the regions are saved after skipping zeros
                        or min/max threshold values. The order of the regions in the file follows
                        the sorting order selected. This is useful, for example, to generate other
                        heatmaps while keeping the sorting of the first heatmap. Example:
                        Heatmap1sortedRegions.bed (default: None)
  --outFileNameMatrix FILE
                        [global] If this option is given, then the matrix of values underlying the
                        plot will be saved using this name. A .gz suffix selects gzip compression;
                        other suffixes write plain text. (default: None)
  --interpolationMethod STR
                        [global] If the heatmap image contains a large number of columns is
                        usually better to use an interpolation method to produce better results
                        (see https://matplotlib.org/examples/images_contours_and_fields/interpolat
                        ion_methods.html). By default, plotHeatmapR uses the method `nearest` if
                        the number of columns is 1000 or less. Otherwise it uses the bilinear
                        method. This default behaviour can be changed by using any of the
                        following options: "nearest", "bilinear", "bicubic", "gaussian" (default:
                        auto)
  --dpi DPI             [global] Set the DPI to save the figure. (default: 200)

Clustering arguments:
  --kmeans KMEANS       [global] Number of clusters to compute. When this option is set, the
                        matrix is split into clusters using the k-means algorithm. Clustering
                        deliberately replaces all existing region groups with the requested
                        clusters. If more specific clustering methods are required, then save the
                        underlying matrix and run the clustering using other software. The
                        plotting of the clustering may fail with an error if a cluster has very
                        few members compared to the total number or regions. (default: None)
  --hclust HCLUST       [global] Number of clusters to compute. When this option is set, then the
                        matrix is split into clusters using the hierarchical clustering algorithm,
                        using "ward linkage". Clustering deliberately replaces all existing region
                        groups with the requested clusters. --hclust could be very slow if you
                        have >1000 regions. In those cases, you might prefer --kmeans or if more
                        clustering methods are required you can save the underlying matrix and run
                        the clustering using other software. The plotting of the clustering may
                        fail with an error if a cluster has very few members compared to the total
                        number of regions. (default: None)
  --silhouette          [global] Compute the silhouette score for regions. This requires --kmeans
                        or --hclust. The score measures how similar a region is to its cluster
                        versus other clusters and is reported in the final column of the BED
                        output. Evaluation can be very slow above 100,000 regions. (default:
                        False)

Common options:
  --help, -h            show this help message and exit
  --version             [global] show program's version number and exit
  --clusterUsingSamples CLUSTERUSINGSAMPLES [CLUSTERUSINGSAMPLES ...]
                        [multiple] List of sample numbers (order as in matrix), that are used for
                        clustering by --kmeans or --hclust if not given, all samples are taken
                        into account for clustering. Example: --ClusterUsingSamples 1 3 (default:
                        None)
  --sortRegions {descend,ascend,no,keep}
                        [global] Whether the heatmap should present the regions sorted. The
                        default is to sort in descending order based on the mean value per region.
                        Note that "keep" and "no" are the same thing. (default: ascend)
  --sortUsing {mean,median,max,min,sum,region_length,score}
                        [global] Indicate which method should be used for sorting. For each row
                        the method is computed. For region_length, a dashed line is drawn at the
                        end of the region (reference point TSS and center) or the beginning of the
                        region (reference point TES) as appropriate. (default: mean)
  --sortUsingSamples SORTUSINGSAMPLES [SORTUSINGSAMPLES ...]
                        [multiple] List of sample numbers (order as in matrix), which are used by
                        --sortUsing for sorting. If no value is set, it uses all samples. Example:
                        --sortUsingSamples 1 3 (default: None)
  --quantileSortedRegions QUANTILESORTEDREGIONS, --quantiles QUANTILESORTEDREGIONS
                        [global] After ascending or descending sorting, regions can be divided
                        into quantiles. The number of quantiles is specified by this option. For
                        example, if you specify 4, then the regions will be divided into
                        quartiles. This is useful to visualize the distribution of the signal
                        across the regions. The default is 1 which means no grouping. Setting > 1
                        will override any existing region groups. Note that this cannot be used
                        with --kmeans or --hclust.
  --filterNans {keep,any_bin,any_sample,all_bins}
                        [global] Drop regions with missing data before clustering, sorting, or
                        plotting. 'keep' (default) never filters on NaNs; 'any_bin' drops a region
                        if any sample has any NaN bin; 'any_sample' drops a region if any sample
                        is entirely NaN; 'all_bins' drops a region only if it is entirely NaN
                        across every sample. This is the same missing-data filter as
                        computeMatrixOperationsR filterValues --filterNans, applied here in-place
                        so a separate filtering step isn't needed just to plot. (default: keep)
  --whatToShow {plot, heatmap and colorbar,heatmap and colorbar}
                        [global] The default is to include a summary or profile plot on top of the
                        heatmap and a heatmap colorbar. Other options are: "heatmap and colorbar"
                        and the default "plot, heatmap and colorbar". (default: plot, heatmap and
                        colorbar)
  --regionsLabel REGIONSLABEL [REGIONSLABEL ...], --regionLabels REGIONSLABEL [REGIONSLABEL ...], -z REGIONSLABEL [REGIONSLABEL ...]
                        [multiple] Labels for the regions plotted in the heatmap. If more than one
                        region is being plotted, a list of labels separated by spaces is required.
                        If a label itself contains a space, then quotes are needed. For example,
                        --regionsLabel label_1, "label 2". (default: None)
  --showRegionCounts    [global] Append the number of plotted regions to every region label, for
                        example "genes [n = 1,234]". This applies to heatmap labels, profile
                        labels, and summary-plot legends. (default: False)
  --samplesLabel SAMPLESLABEL [SAMPLESLABEL ...], --sampleLabels SAMPLESLABEL [SAMPLESLABEL ...]
                        [multiple|explicit|recycled] Labels for the samples plotted. The default
                        is to use the file name of the sample. The sample labels should be
                        separated by spaces and quoted if a label itselfcontains a space E.g.
                        --samplesLabel label-1 "label 2". Use N=label to name a 1-based sample;
                        for example --samplesLabel 2=Case. (default: None)
  --arrangeSamples SAMPLES [SAMPLES ...]
                        [multiple] Create custom profile panels from comma-separated sample
                        indices or names, for example "--arrangeSamples 1,2 3,4". Indices are
                        1-based. Samples not listed are omitted. By default, all samples are
                        plotted in separate panels i.e. --arrangeSamples 1 2 3 ... n while
                        --perGroup creates one set i.e. --arrangeSamples 1,2,3,...,n. The sets are
                        the "sample sets" that per-sample-set options count. (default: None)
  --arrangeGroups GROUP [GROUP ...]
                        [multiple] Region groups to draw, in this order; groups not listed are
                        omitted, everywhere: profiles, heatmaps, limits, region counts and the
                        --outFileSortedRegions and --outFileNameMatrix outputs. One group per
                        value: a 1-based index, a name or an a-b range, for example "--
                        arrangeGroups 3 1 2" or "--arrangeGroups genes 2-4". It addresses the
                        final groups: the clusters of --kmeans/--hclust, the quantiles of
                        --quantiles, or the merged groups of --sameGroupLabels merge. A number is
                        the one the step making the groups gave it (as in the default labels),
                        even when another group is empty. To draw groups in one panel or series
                        use --sameGroupLabels together (comma joins are not accepted); a name then
                        selects every group with that label, and listing only some of them is an
                        error. A listed group that ends up empty or is not formed (fewer populated
                        clusters than requested) is skipped with a warning; an unknown name or a
                        number that can never exist is an error. By default all groups are drawn
                        in order. (default: None)
  --commonLegend [{auto,yes,no}]
                        [global] auto (default): draw one legend when every panel's legend is
                        identical (same labels, colours and line styles in the same order),
                        otherwise as no. yes (also a bare --commonLegend): one legend containing
                        all unique keys, in the first panel for inside locations or figure-level
                        for above, below and right. no: every panel, or every row or column with
                        by_row and by_column, has its own legend. (default: auto)
  --sampleSetLabels LABEL [LABEL ...]
                        [multiple|explicit|recycled] Titles for the sample panels created by
                        --arrangeSamples. By default, joined sample labels are used. One value per
                        sample set (with --groupsAsSampleSets, one per panel in drawing order).
                        Use N=label to name a 1-based sample set. Text accepts \=, \\ and \n.
                        (default: None)
  --sampleSetGroupArrangement {overlay,adjacent,end,by_row,by_column}
                        [global] How region groups are placed within each sample set. overlay
                        (default): all groups as series in one panel. adjacent: one panel per
                        group, right after its sample set. end: the first group for every sample
                        set, then the next group, and so on. by_row: one row per sample set, one
                        panel per group. by_column: one column per sample set, one row per group.
                        by_row and by_column determine the grid shape and override
                        --gridRows/--gridColumns. Split group panels still belong to their sample
                        set: they share its Y/Z limits, colour map, axis labels and sample set
                        label, and a series keeps one colour across them, unless
                        --groupsAsSampleSets makes each panel its own sample set. --perGroup
                        changes the default to adjacent. The panel order also sets the numbering
                        for N= assignments. (default: overlay)
  --gridColumns INT     [global] Number of columns in the panel grid. (default: None)
  --gridRows INT        [global] Number of rows in the panel grid. (default: None)
  --sameGroupLabels {independent,together,merge}
                        [global] How repeated region-group labels are handled. "independent"
                        preserves deepTools behavior; "together" keeps separate series but gives
                        them the same colour; "merge" concatenates their regions before
                        calculating profiles. (default: independent)
  --sameSampleLabels {independent,together}
                        [global] How repeated sample labels are handled if they're in the same
                        panel. "independent" keeps separate colours and legend entries; "together"
                        gives equally named samples the same colour and combines visually
                        identical legend entries. Samples belonging to separate sample sets are
                        treated as independent regardless. (default: independent)
  --xAxisLabel XAXISLABEL [XAXISLABEL ...], -x XAXISLABEL [XAXISLABEL ...]
                        [multiple|explicit|recycled] Description for the X-axis label under the
                        heatmap, one value per sample set (see --arrangeSamples; with
                        --groupsAsSampleSets, one per panel in drawing order). By default it is
                        derived independently for each sample set. (default: None)
  --xAxisVisibility {show_all,outer,outer_merged}
  --axisVisibility {show_all,outer,outer_merged}
                        [global] Set the X-axis and Y-axis visibility at once, superseding both
                        separate visibility options. (default: None)
  --distanceUnit {auto,bp,kb,mb}
                        [global] Unit for numeric distance labels. "auto" uses bp below 1 kb, kb
                        below 1 Mb, and mb otherwise. (default: auto)
  --distanceUnitLocation {ticks,axis}
                        [global] Show the distance unit on every numeric tick or once in square
                        brackets on the X-axis label. (default: ticks)
  --startLabel STARTLABEL [STARTLABEL ...]
                        [multiple|explicit|recycled] [only for scale-regions mode] Label shown in
                        the plot for the start of the region. Default is TSS (transcription start
                        site), but could be changed to anything, e.g. "peak start". Same for the
                        --endLabel option. One value per sample set (see --arrangeSamples; with
                        --groupsAsSampleSets, one per panel in drawing order). Use N=label for a
                        1-based sample set. (default: ['TSS'])
  --endLabel ENDLABEL [ENDLABEL ...]
                        [multiple|explicit|recycled] [only for scale-regions mode] Label shown in
                        the plot for the region end. Default is TES (transcription end site). One
                        value per sample set (see --arrangeSamples; with --groupsAsSampleSets, one
                        per panel in drawing order). Use N=label for a 1-based sample set.
                        (default: ['TES'])
  --refPointLabel REFPOINTLABEL [REFPOINTLABEL ...]
                        [multiple|explicit|recycled] [only for reference-point mode] Label shown
                        in the plot for the reference-point. Default is the same as the reference
                        point selected (e.g. TSS), but could be anything, e.g. "peak start". One
                        value per sample set (see --arrangeSamples; with --groupsAsSampleSets, one
                        per panel in drawing order). Use N=label for a 1-based sample set.
                        (default: None)
  --labelRotation LABEL_ROTATION
                        [global] Rotation of the X-axis labels in degrees. The default is 0,
                        positive values denote a counter-clockwise rotation. (default: 0.0)
  --linesAtTickMarks    [global] Draw dashed lines from all tick marks through the heatmap. This
                        is then similar to the dashed line draw at region bounds when using a
                        reference point and --sortUsing region_length (default: False)
  --minorTickMarks none|auto|INT
                        [global] Minor X-axis ticks: none disables them, auto chooses natural
                        spacing based on the available width while preserving landmark ticks, and
                        an integer sets the total number of minor ticks across the axis,
                        distributed proportionally between landmark ticks. (default: none)
  --plotTitle PLOTTITLE, -T PLOTTITLE
                        [global] Title of the plot, to be printed on top of the generated image.
                        Leave blank for no title. (default: )
  --perGroup            [global] By default each sample is its own sample set and panel, and
                        region groups are its series. --perGroup does the opposite: all samples
                        form one sample set whose panels are the region groups, with the samples
                        as series. It is a shortcut for --arrangeSamples 1,2,...,n
                        --sampleSetGroupArrangement adjacent; your own --arrangeSamples or
                        --sampleSetGroupArrangement replaces either part (e.g.
                        end/by_row/by_column change the panel order). The group panels remain one
                        sample set, so they share one colour scale (deepTools 3.5.6 cycled
                        --colorMap/--zMin/--zMax per group): add --groupsAsSampleSets to give each
                        its own limits, colour maps, labels and series colours. (default: False)
  --groupsAsSampleSets  [global] Make every region-group panel a separate sample set, numbered in
                        drawing order. Per-sample-set options (--yMin, --yMax, --zMin, --zMax,
                        --colorMap, --yAxisLabel, --sampleSetLabels, ...) then take one value per
                        panel, in drawing order, and series colours are assigned per series per
                        sample set, so --colors needs a colour for every series in every panel.
                        Has no effect (warning) when groups are overlaid in one panel. (default:
                        False)
  --plotFileFormat      [global] Image format type. If given, this option overrides the image
                        format based on the plotFile ending. The available options are: "png",
                        "eps", "pdf" and "svg" (default: None)
  --textHinting {on,off}
                        [global] Glyph hinting for this run, overriding the text_hinting setting
                        in options.txt (default off). off: exact text spacing, identical in PDF,
                        SVG and PNG; on: crisper small text in raster output, with spacing snapped
                        to whole pixels. (default: None)
  --verbose             [global] If set, warning messages and additional information are given.
                        (default: False)

Heatmap options:
  --heatmapHeight HEATMAPHEIGHT
                        [global] Whole heatmap-stack height in cm; by default the cell width
                        divided by the aspect ratio (10 cm when no size is set). Any two of cell
                        width, height and aspect ratio determine the third. (default: None)
  --heatmapWidth CELLWIDTH
                        [global] Cell width in cm; default 5, and any two of width, heatmap height
                        and aspect ratio determine the third. (default: None)
  --aspectRatio ASPECTRATIO
                        [global] Cell width divided by whole heatmap-stack height; default 0.5,
                        and any two sizes determine the third. The stack includes blocks and gaps,
                        excluding titles, axes, summary plots and colorbars. (default: None)
  --regionLabelLocation {left,right}
                        [global] Place region-group labels to the left of the heatmap or to its
                        right, inside any right-hand colorbar. (default: right)
  --yAxisLabel YAXISLABEL [YAXISLABEL ...], -y YAXISLABEL [YAXISLABEL ...]
                        [multiple|explicit|recycled] Description for the heatmap Y axis, evaluated
                        once per sample set (see --arrangeSamples; with --groupsAsSampleSets, one
                        per panel in drawing order) and recycled as necessary. (default: [''])
  --colorbarLocation {best,right,right_common,bottom,below,below_common}
                        [global] Place heatmap colorbars automatically ("best": below the heatmaps
                        when there are several colour scales, otherwise to the right of each row),
                        per row to the right, or below the heatmaps. "below" is an alias for
                        "bottom" (one bar per column). "below_common" dedups identical colour

                        "right_common" packs one grid of distinct bars to the right of the full
                        figure. (default: best)
  --colorbarLabels LABEL [LABEL ...]
                        [multiple|explicit|recycled] Titles drawn above each colorbar. "none"
                        (default) draws no title; "auto" uses the sample label(s) of the
                        heatmap(s) that colorbar serves (joined with newlines when it serves

                        centred on the heatmap(s) it serves. (default: None)
  --sortIndicator {auto,none}
                        [global] Draw a sorting-direction triangle when the effective region sort
                        is ascending or descending. "none" disables it. (default: auto)
  --colorMap COLORMAP [COLORMAP ...]

                        than one heatmap is being plotted the color of each heatmap can be enter
                        individually (e.g. `--colorMap Reds Blues`). Color maps are recycled if
                        the number of color maps is smaller than the number of sample sets (see
                        --arrangeSamples; with --groupsAsSampleSets, one per panel in drawing
                        order). Use N=name for a 1-based sample set. Available values can be seen
                        here: http://matplotlib.org/users/colormaps.html The available options
                        are: 'RdYlBu', 'Reds', 'viridis' (default: ['RdYlBu'])
  --alpha ALPHA         [global] The alpha channel (transparency) to use for the heatmaps. The
                        default is 1.0 and values must be between 0 and 1. (default: 1.0)
  --colorList COLORLIST [COLORLIST ...]
                        [multiple|explicit|recycled] List of colors to use to create a colormap.
                        For example, if `--colorList black,yellow,blue` is set (colors separated
                        by comas) then a color map that starts with black, continues to yellow and

                        `--colorList "white,#cccccc" "white,darkred"` As for --colorMap, the color
                        lists are recycled if their number is smaller than the number of sample
                        sets (one per sample set; with --groupsAsSampleSets, one per panel in
                        drawing order). Use N=colors for a 1-based sample set. The number of
                        transitions is defined by the --colorNumber option. (default: None)
  --colorNumber COLORNUMBER
                        [global] N.B., --colorList is required for an effect. This controls the
                        number of transitions from one color to the other. If --colorNumber is the
                        number of colors in --colorList then there will be no transitions between

  --missingDataColor MISSINGDATACOLOR
                        [global] If --missingDataAsZero was not set, such cases will be colored in

                        http://packages.python.org/ete2/reference/reference_svgcolors.html. Other

  --boxAroundHeatmaps BOXAROUNDHEATMAPS

  --zMax ZMAX [ZMAX ...], -max ZMAX [ZMAX ...]
                        [multiple|explicit|recycled] Maximum value for the heatmap intensities.

Summary plot options:
  --outFileNameData OUTFILENAMEDATA
                        [global] File name for a tab-separated table containing the exact plotted
                        centre and optional lower/upper profile bounds for every displayed panel
                        and series, e.g. myProfile.tab. (default: None)
  --heightSummaryPlot HEIGHTSUMMARYPLOT
                        [global] Summary-profile height in cm; by default the cell width divided
                        by the aspect ratio. Any two of cell width, height and aspect ratio
                        determine the third. (default: None)
  --plotTypeSummaryPlot {lines,fill,se,std,ci,bootstrap}
                        [global] "lines" will plot the profile line based on the average type
                        selected. "fill" fills the region between zero and the profile curve. The
                        fill in color is semi transparent to distinguish different profiles. "se"
                        and "std" color the region between the profile and the standard error or
                        standard deviation of the data. Standard error uses finite observations
                        independently in each bin and is hidden when fewer than two are available;
                        this intentionally differs from stock deepTools. "ci" shades the analytic
                        confidence interval of a mean or geom_mean and "bootstrap" a percentile-
                        bootstrap interval of any average type (see --ci_level). (default: lines)
  --averageTypeSummaryPlot {mean,geom_mean,trim_mean,median,min,max,std,sum}
                        [global] Define the type of statistic that should be plotted in the
                        summary image above the heatmap. (default: mean)
  --pseudocountSummaryPlot PSEUDOCOUNTSUMMARYPLOT
                        [global] Pseudocount used by geom_mean in the summary plot. A negative
                        value selects half the smallest nonzero magnitude. All-zero data resolves
                        to zero; mixed signs within one bin are invalid. (default: -1)
  --trimPercSummaryPlot TRIMPERCSUMMARYPLOT
                        [global] Fraction removed from each tail independently in every bin when
                        using trim_mean in the summary plot. (default: 0.05)
  --aspectRatioSummaryPlot ASPECTRATIOSUMMARYPLOT
                        [global] Cell width divided by summary-profile height; default 1, and any
                        two sizes determine the third. (default: None)
  --yAxisVisibilitySummaryPlot {show_all,outer,outer_merged}
  --yAxisLimitsSummaryPlot {common,per_panel,per_sample_set,per_y_label}
  --yMinSummaryPlot YMINSUMMARYPLOT [YMINSUMMARYPLOT ...]
                        [multiple|explicit|recycled] Minimum value for the Y-axis. One value per
                        sample set (see --arrangeSamples; with --groupsAsSampleSets, one per panel
                        in drawing order), separated by spaces. If there are fewer values than
                        sample sets, the values are recycled. Use N=value for a 1-based sample
                        set. (default: None)
  --yMaxSummaryPlot YMAXSUMMARYPLOT [YMAXSUMMARYPLOT ...]
                        [multiple|explicit|recycled] Maximum value for the Y-axis. One value per
                        sample set (see --arrangeSamples; with --groupsAsSampleSets, one per panel
                        in drawing order), separated by spaces. If there are fewer values than
                        sample sets, the values are recycled. Use N=value for a 1-based sample
                        set. (default: None)
  --yAxisLabelSummaryPlot YAXISLABELSUMMARYPLOT [YAXISLABELSUMMARYPLOT ...]
                        [multiple|recycled] Y-axis label for the summary plot. (default: [''])
  --colorsSummaryPlot COLORSSUMMARYPLOT [COLORSSUMMARYPLOT ...], --plotColorsSummaryPlot COLORSSUMMARYPLOT [COLORSSUMMARYPLOT ...]
                        [multiple] One colour per series, in drawing order (a series is what its
                        line's label names: a sample, a region group, or a group-sample pair; for
                        example --arrangeSamples 1,3 2,4 gives series S1, S3, S2, S4, so N=2 is

  --legendLocationSummaryPlot {best,upper-right,upper-left,upper-center,lower-left,lower-right,lower-center,center,center-left,center-right,above,top,below,bottom,right,none}
                        [global] Location for the legend in the summary plot. "above" or "top"

                        "bottom" places it below the Y-axis, "right" places it outside the plots;
                        "none" hides it. (default: best)
  --ci_level CI_LEVEL   [global] Confidence level for confidence intervals. Applicable if
                        --plotTypeSummaryPlot is "ci" or "bootstrap". (default: 0.95)
  --bootstrapReplicates BOOTSTRAPREPLICATES
                        [global] Number of bootstrap resamples used by --plotTypeSummaryPlot
                        bootstrap. (default: 300)

An example usage is: plotHeatmapR -m matrix.gz

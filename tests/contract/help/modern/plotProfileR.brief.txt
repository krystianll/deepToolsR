usage: plotProfileR -m matrix.gz
help: plotProfileR -h / plotProfileR --help

This tool creates a profile plot for scores over sets of genomic regions. Typically, these regions
are genes, but any other regions defined in BED will work. A matrix generated by computeMatrixR is
required.

options:
  --config PATH         [global] Options file path, or auto for the default file. (default: auto)

Required arguments:
  --matrixFile, -m MATRIXFILE
                        [global] Matrix file from the computeMatrixR tool. (default: None)
  --outFileName, -out, -o OUTFILENAME
                        [global] File name to save the image to. The file ending will be used to
                        determine the image format. The available options are: "png", "eps", "pdf"
                        and "svg", e.g., MyHeatmap.png.

Output options:
  --outFileSortedRegions FILE
                        [global] File name into which the regions are saved after skipping zeros
                        or min/max threshold values. The order of the regions in the file follows
                        the sorting order selected. This is useful, for example, to generate other
                        heatmaps while keeping the sorting of the first heatmap. Example:
                        Heatmap1sortedRegions.bed (default: None)
  --outFileNameMatrix FILE
                        [global] If this option is given, then the matrix of values underlying the
                        plot will be saved using this name. A .gz suffix selects gzip compression;
                        other suffixes write plain text. (default: None)
  --outFileNameData OUTFILENAMEDATA
                        [global] File name for a tab-separated table containing the exact plotted
                        centre and optional lower/upper profile bounds for every displayed panel
                        and series, e.g. myProfile.tab. (default: None)
  --dpi DPI             [global] Set the DPI to save the figure. (default: 200)

Clustering arguments:
  --kmeans KMEANS       [global] Number of clusters to compute. When this option is set, the
                        matrix is split into clusters using the k-means algorithm. Clustering
                        deliberately replaces all existing region groups with the requested
                        clusters. If more specific clustering methods are required, then save the
                        underlying matrix and run the clustering using other software. The
                        plotting of the clustering may fail with an error if a cluster has very
                        few members compared to the total number or regions. (default: None)
  --hclust HCLUST       [global] Number of clusters to compute. When this option is set, then the
                        matrix is split into clusters using the hierarchical clustering algorithm,
                        using "ward linkage". Clustering deliberately replaces all existing region
                        groups with the requested clusters. --hclust could be very slow if you
                        have >1000 regions. In those cases, you might prefer --kmeans or if more
                        clustering methods are required you can save the underlying matrix and run
                        the clustering using other software. The plotting of the clustering may
                        fail with an error if a cluster has very few members compared to the total
                        number of regions. (default: None)
  --silhouette          [global] Compute the silhouette score for regions. This requires --kmeans
                        or --hclust. The score measures how similar a region is to its cluster
                        versus other clusters and is reported in the final column of the BED
                        output. Evaluation can be very slow above 100,000 regions. (default:
                        False)

Optional arguments:
  --help, -h            show this help message and exit
  --version             [global] show program's version number and exit
  --clusterUsingSamples CLUSTERUSINGSAMPLES [CLUSTERUSINGSAMPLES ...]
                        [multiple] List of sample numbers (order as in matrix), that are used for
                        clustering by --kmeans or --hclust if not given, all samples are taken
                        into account for clustering. Example: --ClusterUsingSamples 1 3 (default:
                        None)
  --sortRegions {descend,ascend,no,keep}
                        [global] Whether the heatmap should present the regions sorted. The
                        default is to sort in descending order based on the mean value per region.
                        Note that "keep" and "no" are the same thing. (default: ascend)
  --sortUsing {mean,median,max,min,sum,region_length,score}
                        [global] Indicate which method should be used for sorting. For each row
                        the method is computed. For region_length, a dashed line is drawn at the
                        end of the region (reference point TSS and center) or the beginning of the
                        region (reference point TES) as appropriate. (default: mean)
  --sortUsingSamples SORTUSINGSAMPLES [SORTUSINGSAMPLES ...]
                        [multiple] List of sample numbers (order as in matrix), which are used by
                        --sortUsing for sorting. If no value is set, it uses all samples. Example:
                        --sortUsingSamples 1 3 (default: None)
  --quantileSortedRegions, --quantiles QUANTILESORTEDREGIONS
                        [global] After ascending or descending sorting, regions can be divided
                        into quantiles. The number of quantiles is specified by this option. For
                        example, if you specify 4, then the regions will be divided into
                        quartiles. This is useful to visualize the distribution of the signal
                        across the regions. The default is 1 which means no grouping. Setting > 1
                        will override any existing region groups. Note that this cannot be used
                        with --kmeans or --hclust.
  --filterNans {keep,any_bin,any_sample,all_bins}
                        [global] Drop regions with missing data before clustering, sorting, or
                        plotting. 'keep' (default) never filters on NaNs; 'any_bin' drops a region
                        if any sample has any NaN bin; 'any_sample' drops a region if any sample
                        is entirely NaN; 'all_bins' drops a region only if it is entirely NaN
                        across every sample. This is the same missing-data filter as
                        computeMatrixOperationsR filterValues --filterNans, applied here in-place
                        so a separate filtering step isn't needed just to plot. (default: keep)
  --plotType {lines,fill,se,std,ci,bootstrap,heatmap}
                        [global] "lines" will plot the profile line based on the average type
                        selected. "fill" fills the region between zero and the profile curve. The
                        fill in color is semi transparent to distinguish different profiles. "se"
                        and "std" color the region between the profile and the standard error or
                        standard deviation of the data. Standard error uses the finite observation
                        count independently in each bin (unlike stock deepTools) and is hidden
                        when fewer than two finite values are available. As in the case of fill, a
                        semi-transparent color is used. "ci" shades the analytic confidence
                        interval of a mean or geom_mean and "bootstrap" a percentile-bootstrap
                        interval of any average type (see --ci_level). "heatmap" plots a summary
                        heatmap. (default: lines)
  --averageType {mean,geom_mean,trim_mean,median,min,max,std,sum}
                        [global] The type of statistic that should be used for the profile.
                        "geom_mean" requires nonzero observations within each bin to have the same
                        sign; "trim_mean" trims values independently in each bin. (default: mean)
  --pseudocount PSEUDOCOUNT
                        [global] Pseudocount used by the geometric mean. A negative value (the
                        default) automatically uses half the smallest positive magnitude in the
                        profile data, excluding zeros. All-zero data resolves to zero. Zero is
                        accepted explicitly and preserves zero observations; analytic log-space
                        bands need a positive pseudocount for bins containing both zero and
                        nonzero observations. (default: -1)
  --trim_perc TRIM_PERC
                        [global] Fraction to trim from each tail for trimmed means. (default:
                        0.05)
  --ci_level CI_LEVEL   [global] Confidence level for confidence intervals. Applicable if
                        --plotType is "ci" or "bootstrap". (default: 0.95)
  --bootstrapReplicates BOOTSTRAPREPLICATES
                        [global] Number of bootstrap resamples used by --plotType bootstrap.
                        (default: 300)
  -p, --numberOfProcessors N|max|auto
                        [global] Threads: positive integer, max, or auto. (default: auto)
  --plotHeight, --profileHeight PLOTHEIGHT
                        [global] Profile height in cm; by default the cell width divided by the
                        aspect ratio (5 cm when no size is set). Any two of cell width, height and
                        aspect ratio determine the third. (default: None)
  --plotWidth, --profileWidth PLOTWIDTH
                        [global] Cell width in cm; default 5, and any two of width, profile height
                        and aspect ratio determine the third. (default: None)
  --aspectRatio ASPECTRATIO
                        [global] Cell width divided by profile height; default 1, and any two
                        sizes determine the third. (default: None)
  --arrangeSamples SAMPLES [SAMPLES ...]
                        [multiple] Create custom profile panels from comma-separated sample
                        indices or names, for example "--arrangeSamples 1,2 3,4". Indices are
                        1-based. Samples not listed are omitted. By default, all samples are
                        plotted in separate panels i.e. --arrangeSamples 1 2 3 ... n while
                        --perGroup creates one set i.e. --arrangeSamples 1,2,3,...,n. (default:
                        None)
  --commonLegend        [global] By default, every panel or sample set has its own legend. With
                        this setting, you can replace them with one figure-level legend containing
                        all unique keys. (default: False)
  --sampleSetLabels LABEL [LABEL ...]
                        [multiple|explicit|recycled] Titles for the sample panels created by
                        --arrangeSamples. By default, joined sample labels are used. Use N=label
                        to name a 1-based sample set. Text accepts \=, \\ and \n. (default: None)
  --sampleSetGroupArrangement {overlay,adjacent,end,by_row,by_column}
                        [global] Placement of additional logical region groups: overlay them as
                        extra series, place group panels immediately after each sample set panel,
                        or place them at the end after the first group has been plotted for every
                        sample panel. "by_row" places region groups in one row while the next
                        sample set occupies the next row; "by_column" places sample sets in
                        columns while region groups are added as rows. These two modes determine
                        the grid shape and override --gridRows/--gridColumns. (default: overlay)
  --gridColumns INT     [global] Number of columns in the panel grid. (default: None)
  --gridRows INT        [global] Number of rows in the panel grid. (default: None)
  --xAxisLabel, -x XAXISLABEL [XAXISLABEL ...]
                        [multiple|explicit|recycled] Description for the X-axis label. By default,
                        a label such as "distance from TSS" is generated from the input. The
                        distance unit is placed according to --distanceUnitLocation. You can have
                        multiple X-axis labels and they are assigned per sample set specified by
                        --arrangeSamples. Use N=label for a 1-based sample set. (default: None)
  --yAxisLabel, -y YAXISLABEL [YAXISLABEL ...]
                        [multiple|explicit|recycled] Description for the Y-axis label. You can
                        have multiple Y-axis labels and they are assigned per sample set specified
                        by --arrangeSamples, e.g. --yAxisLabel RNA-seq RNA-seq ChIP-seq ChIP-seq.
                        Use N=label for a 1-based sample set. (default: [''])
  --xAxisVisibility {show_all,outer,outer_merged}
                        [global] If you have multiple rows of panels, this setting controls
                        whether identical X-axis labels should be shown for all rows. "outer"
                        keeps one label per column per compatible set of rows; "outer_merged" is
                        like "outer" but only one label is shown for all compatible columns. Tick
                        marks remain visible. (default: outer)
  --yAxisVisibility {show_all,outer,outer_merged}
                        [global] If you have multiple columns of panels, this setting controls
                        whether identical Y-axis labels should be shown for all columns. "outer"
                        keeps one label per row per compatible set of columns; "outer_merged" is
                        like "outer" but only one label is shown for all compatible rows. This
                        will also hide Y-axis values if panels in the affected row have the same
                        limits. Tick marks remain visible. (default: outer)
  --axisVisibility {show_all,outer,outer_merged}
                        [global] Set the X-axis and Y-axis visibility at once, superseding both
                        separate visibility options. (default: None)
  --yAxisLimits {common,per_panel,per_sample_set,per_y_label}
                        [global] Determine Y limits globally, independently per panel, per sample
                        set, or per distinct Y-axis label. (default: per_y_label)
  --yMin YMIN [YMIN ...]
                        [multiple|explicit|recycled] Minimum value for the Y-axis. Multiple
                        values, separated by spaces can be set for each profile. If the number of
                        yMin values is smaller thanthe number of plots, the values are recycled.
                        Use N=value for a 1-based sample set. (default: None)
  --yMax YMAX [YMAX ...]
                        [multiple|explicit|recycled] Maximum value for the Y-axis. Multiple
                        values, separated by spaces can be set for each profile. If the number of
                        yMin values is smaller thanthe number of plots, the values are recycled.
                        Use N=value for a 1-based sample set. (default: None)
  --distanceUnit {auto,bp,kb,mb}
                        [global] Unit for numeric distance labels. "auto" uses bp below 1 kb, kb
                        below 1 Mb, and mb otherwise. (default: auto)
  --distanceUnitLocation {ticks,axis}
                        [global] Show the distance unit on every numeric tick or once in square
                        brackets on the X-axis label. (default: ticks)
  --startLabel STARTLABEL [STARTLABEL ...]
                        [multiple|explicit|recycled] [only for scale-regions mode] Label shown in
                        the plot for the start of the region. Default is TSS (transcription start
                        site), but could be changed to anything, e.g. "peak start". Same for the
                        --endLabel option. See below. Use N=label for a 1-based sample set.
                        (default: ['TSS'])
  --endLabel ENDLABEL [ENDLABEL ...]
                        [multiple|explicit|recycled] [only for scale-regions mode] Label shown in
                        the plot for the region end. Default is TES (transcription end site). Use
                        N=label for a 1-based sample set. (default: ['TES'])
  --refPointLabel REFPOINTLABEL [REFPOINTLABEL ...]
                        [multiple|explicit|recycled] [only for reference-point mode] Label shown
                        in the plot for the reference-point. Default is the same as the reference
                        point selected (e.g. TSS), but could be anything, e.g. "peak start". Use
                        N=label for a 1-based sample set. (default: None)
  --labelRotation LABEL_ROTATION
                        [global] Rotation of the X-axis labels in degrees. The default is 0,
                        positive values denote a counter-clockwise rotation. (default: 0.0)
  --linesAtTickMarks    [global] Draw dashed vertical lines from every X-axis tick mark across
                        each profile panel, matching the equivalent plotHeatmap option. (default:
                        False)
  --regionsLabel, --regionLabels, -z REGIONSLABEL [REGIONSLABEL ...]
                        [multiple] Labels for the regions plotted in the heatmap. If more than one
                        region is being plotted, a list of labels separated by spaces is required.
                        If a label itself contains a space, then quotes are needed. For example,
                        --regionsLabel label_1, "label 2". (default: None)
  --showRegionCounts    [global] Append the number of plotted regions to every region label, for
                        example "genes [n = 1,234]". This applies to heatmap labels, profile
                        labels, and summary-plot legends. (default: False)
  --samplesLabel, --sampleLabels SAMPLESLABEL [SAMPLESLABEL ...]
                        [multiple|explicit|recycled] Labels for the samples plotted. The default
                        is to use the file name of the sample. The sample labels should be
                        separated by spaces and quoted if a label itselfcontains a space E.g.
                        --samplesLabel label-1 "label 2". Use N=label to name a 1-based sample;
                        for example --samplesLabel 2=Case. (default: None)
  --sameGroupLabels {independent,together,merge}
                        [global] How repeated region-group labels are handled. "independent"
                        preserves deepTools behavior; "together" keeps separate series but gives
                        them the same colour and, with --perGroup, puts them in one panel; "merge"
                        concatenates their regions before calculating profiles. (default:
                        independent)
  --sameSampleLabels {independent,together}
                        [global] How repeated sample labels are handled if they're in the same
                        panel. "independent" keeps separate colours and legend entries; "together"
                        gives equally named samples the same colour and combines visually
                        identical legend entries. Samples belonging to separate sample sets are
                        treated as independent regardless. (default: independent)
  --colorsPerSample, --colors, --plotColors COLORS [COLORS ...]
                        [multiple|explicit] One colour per plotted sample line, in the order the
                        lines appear (which follows --arrangeSamples). Colour names and html hex
                        strings (e.g., #eeff22) are accepted, space separated, for example
                        --colorsPerSample red blue green. A plain list must name exactly one
                        colour per distinctly coloured line (with --plotType heatmap, one colour
                        map per panel); a shorter list is an error, extra values are ignored with
                        a warning. N=colour sets coloured series N in legend order; any subset may
                        be set, e.g. --colorsPerSample 1,2=red 3-4=blue (unnamed lines take the
                        default); plain entries mixed with N= entries fill the remaining series in
                        order. If you also use --sameSampleLabels, note that it is resolved before
                        colours are assigned, so you should not provide colours twice for samples
                        that are to be collapsed. (default: None)
  --legendLocation {best,upper-right,upper-left,upper-center,lower-left,lower-right,lower-center,center,center-left,center-right,above,top,below,bottom,right,none}
                        [global] Location for the legend in the summary plot. "above" or "top"
                        places the legend between the main title and subplot titles; , "below" or
                        "bottom" places it below the Y-axis, "right" places it outside the plots;
                        "none" hides it. (default: best)
  --minorTickMarks none|auto|INT
                        [global] Minor X-axis ticks: none disables them, auto chooses natural
                        spacing based on the available width while preserving landmark ticks, and
                        an integer sets the total number of minor ticks across the axis,
                        distributed proportionally between landmark ticks. (default: none)
  --plotTitle, -T PLOTTITLE
                        [global] Title of the plot, to be printed on top of the generated image.
                        Leave blank for no title. (default: )
  --perGroup            [global] The default is to plot all groups of regions by sample. Using
                        this option instead plots all samples by group of regions. Note that this
                        is only useful if you have multiple groups of regions. by sample rather
                        than group. (default: False)
  --plotFileFormat      [global] Image format type. If given, this option overrides the image
                        format based on the plotFile ending. The available options are: "png",
                        "eps", "pdf" and "svg" (default: None)
  --verbose             [global] If set, warning messages and additional information are given.
                        (default: False)

An example usage is: plotProfileR -m matrix.gz
